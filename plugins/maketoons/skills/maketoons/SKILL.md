# MakeToons

짧은 아이디어를 컷별 이야기와 실제 이미지로 만든다. 기본 언어는 한국어이며 사용자 요청이 기본값보다 우선한다.

## 안내와 콘티

- 처음 사용하거나 사용법을 물으면 짧게 안내한다: “소재만 알려주세요. 기본은 4컷을 2×2 한 장으로 만들어요. 대사 없이 만들거나 컷별로 따로 저장할 수도 있어요.” 충분한 요청을 받았다면 안내 때문에 멈추지 않는다.
- 아이디어만 있으면 제목, 컷 수, 배치, 출력 이미지 수, 텍스트 방식을 정하고 `컷 | 장면·표정·동작 | 이미지에 들어갈 정확한 텍스트` 표로 짧은 콘티를 제안한다. 기본은 4컷·2×2·한 장이다. 핵심 정보가 없을 때만 질문한다.
- 기본은 콘티를 보여준 뒤 생성 요청을 기다린다. “알아서 바로 생성”, “콘티 확인 없이”처럼 허용한 경우 내부적으로 구성을 정하고 바로 생성한다. 완성된 콘티와 생성 요청을 받았다면 재승인을 요구하지 않는다.
- “대사 없어도 돼”는 무텍스트 구성을 제안해도 좋다. `무텍스트`는 말풍선·내레이션·효과음·간판 글자·컷 번호까지 이미지 안에 넣지 않는 방식이다. “대사만 빼고 효과음은 넣어” 같은 구체적 요청은 우선한다. 표정과 동작만으로 사건과 결말이 읽히게 한다.
- 수정 요청은 해당 컷 중심으로 반영하고 이미 정한 형식과 설정은 이어간다. 장문의 설문을 요구하지 않는다.

## 기준 이미지

생성·검수 전에 [강별이 기준](references/character.md)과 [기준 파일 목록](assets/reference-set.json)을 읽는다. 상대 경로는 이 SKILL.md가 있는 디렉터리 기준이다.

- 포함된 원본을 실제로 열어 보고 이미지 생성 도구의 참조 이미지 입력으로 전달한다. 파일명이나 외형 설명만 프롬프트에 적은 것은 참조 입력이 아니다.
- 현재 기준은 `gangbyul-v1`: 1번은 외형·비율, 2번은 색과 표정, 4번은 배경과 채색 질감이다. 3번은 포함하지도 사용하지도 않는다.
- 한 회차는 시작 시 선택한 기준 버전을 유지한다. 현재 컷 수정은 팀 기준 변경으로 취급하지 않는다. 패키지 원본과 설치 캐시는 수정하지 않는다.
- 사용자가 회차용 대체 이미지를 지정하면 그 범위를 따른다. 기준 파일을 읽을 수 없거나 도구에 전달할 수 없으면 그렇게 알리고 필요한 이미지를 채팅에 첨부해 달라고 요청한다. 참조했다고 꾸미지 않는다. 콘티 작업은 계속할 수 있다.

## 생성과 수정

- 현재 환경에 제공되는 이미지 생성·편집 도구를 사용하고 그 도구의 지침을 따른다. 도구가 없다면 콘티와 프롬프트까지 제공하고 이미지 생성 불가를 설명한다. 별도 API 키, 외부 이미지 서비스나 유료 API를 자동으로 요구하거나 사용하지 않는다.
- 편집 대상과 기준 이미지를 함께 넣을 수 있으면 함께 전달하고 각 이미지의 역할을 명시한다. 입력 제한으로 전부 넣을 수 없다면 필요한 기준을 선택하고 생략한 내용을 기록한다.
- 한 장 요청은 한 캔버스 안에 지정한 컷 수와 배치를 만든다. 컷 수와 파일 수는 다르다. 각 컷 따로 요청할 때만 파일을 나눈다.
- 프롬프트에는 유지할 특징, 컷별 장면, 정확한 대사 또는 글자 금지, 배치와 읽는 순서, 변경 범위를 포함한다. 기준 시트의 정면·측면·후면이나 표정 이름을 완성 툰에 복제하지 않는다.
- 수정은 해당 결과 이미지를 편집 대상으로 삼고 변경할 부분을 한정한다. 다른 컷과 확정 대사는 유지하도록 요청한다. 픽셀 단위 동일성을 보장하지 않는다.
- 실제 결과를 열어 컷 수·순서, 별 장식과 신체 비율, 대사 정확성 또는 글자 부재를 점검한다. 명확한 불일치는 한 번의 집중 수정으로 해결을 시도한다. 이후 남은 문제는 알리고 다음 수정 방향을 제안한다. 무한 재생성하지 않는다.

## 결과 전달과 저장

생성 후 [저장 지침](references/output.md)을 따른다. 로컬 작업 폴더가 확인되는 환경은 그 폴더의 `.thesameimgs/outputs/`에 저장한다. 웹의 임시 실행 폴더를 사용자 컴퓨터의 프로젝트로 간주하지 않는다.

- 한 장 툰: `YYYYMMDD_HHMMSS_제목.png` — 여러 컷이어도 컷 번호 없음.
- 개별 컷: `YYYYMMDD_HHMMSS_제목_01컷.png`.
- 수정본은 `_수정01` 등을 붙여 새 파일로 보존한다. 시각은 Asia/Seoul의 실제 현재 시각, 확장자는 실제 이미지 형식이다.
- 지원되는 환경에서는 저장 도우미로 원본 바이트를 복사하고 기준 버전·컷 수·형식을 담은 JSON 기록을 함께 남긴다. 저장을 위해 이미지를 재생성하지 않는다.
- 로컬 접근이 없는 웹 환경은 다운로드 파일과 가능한 경우 제작 기록을 제공한다. 파일명 변경도 불가능하면 도구의 이미지와 권장 파일명을 안내한다. 로컬 저장 성공을 주장하지 않는다.
- 최종 응답은 결과 이미지/파일 링크, 실제 저장 위치 또는 다운로드 안내, 기준 버전과 남은 문제를 간단히 제시한다. 요청 없이 SNS에 게시하지 않는다.
