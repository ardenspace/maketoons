# MakeToons

강별이 기준 이미지로 콘티를 함께 짜고 SNS 툰을 만드는 팀용 스킬·플러그인입니다.

## 사용하기

설치한 환경의 새 대화에서 MakeToons를 선택하고 소재를 보내세요.

> 강별이가 월요일에 출근하기 싫어하는 내용으로 콘티를 짜 줘. 대사 없이 네 컷을 한 장으로.

소재만 보내면 컷별 장면과 텍스트를 제안합니다. 기본은 **4컷 · 2×2 · 한 장**입니다. 콘티를 수정한 뒤 “이대로 생성해 줘”라고 요청하세요. “알아서 바로 만들어 줘”라고 하면 콘티 확인을 생략합니다. “세로로 네 컷”, “각각 따로”, “대사는 없고 효과음만”도 지정할 수 있습니다.

생성·수정은 사용 환경에 제공되는 이미지 도구를 사용합니다. 이 패키지는 API 키나 별도 생성 서버를 요구하지 않습니다. 구독의 이미지 생성 제공 여부와 사용 한도는 각 계정에 따릅니다.

## 포함된 기준

`gangbyul-v1`에는 디자이너가 제공한 원본 3장이 들어 있습니다.

| 파일 | 역할 |
|---|---|
| gangbyul.png (1번) | 외형과 정면·측면·후면 비율 |
| gangbyul2.png | 노란 별, 컬러 캐릭터와 표정 |
| gangbyul4.png | 강별상회 배경과 채색 질감 |

**gangbyul3.png는 제외했습니다.** 스킬은 원본을 열고 실제 생성 참조 입력으로 전달하도록 지시합니다. 파일에 접근할 수 없는 환경에서는 첨부를 요청합니다. 일관성이나 픽셀 단위 동일성을 보장하지 않습니다.

## 설치와 공유

### Codex 앱·CLI

이 저장소에는 `.agents/plugins/marketplace.json`과 `plugins/maketoons/`가 있습니다. 저장소 배포 목록 이름은 `maketoons-team`이며 기존 개인 `personal` 목록과 별개입니다.

```bash
codex plugin marketplace add https://github.com/ardenspace/maketoons.git
codex plugin add maketoons@maketoons-team
```

설치 후 **새 대화**에서 `$maketoons`를 사용합니다. 앱에서 제공하는 플러그인 공유 기능도 사용할 수 있습니다. 기존 `gangbyul-thesameimages`가 함께 설치되어 있으면 새 작업에서는 MakeToons를 명시적으로 선택하세요. 이 저장소는 기존 플러그인을 자동 삭제하지 않습니다.

### ChatGPT 웹·모바일

GitHub 저장소에 올렸다는 사실만으로 ChatGPT 플러그인 목록에 등록되지는 않습니다. 계정에 제공되는 플러그인 생성·공유 또는 스킬 가져오기 경로를 통해 배포해야 합니다. 일반 ChatGPT의 첨부란에 ZIP을 올리는 것과 플러그인 설치는 다릅니다.

관리자는 아래 명령으로 플러그인 ZIP과 단독 스킬 ZIP을 만들 수 있습니다. 해당 계정의 지원되는 가져오기 화면에 맞는 패키지를 사용합니다. 웹·모바일 설치, 패키지 이미지의 생성 참조 전달, 다운로드 동작은 팀원 계정에서 별도 검증해야 합니다. 미지원 환경은 기준 이미지 3장과 지침을 직접 첨부해 사용할 수 있습니다.

```bash
python3 scripts/package_plugin.py
```

## 저장

로컬 작업 폴더에서는 `makeimgs/outputs/`에 **한국 시간**으로 저장합니다. 플러그인 설치 폴더에는 저장하지 않습니다.

```text
makeimgs/outputs/
  20260925_143052_월요일_출근.png
  20260925_143052_월요일_출근.json
  20260925_144205_월요일_출근_수정01.png
```

네 컷을 한 장으로 만들면 컷 번호가 없습니다. 개별 파일 요청에만 `_01컷`이 붙습니다. 같은 시각·제목이면 추가 번호로 기존 파일을 보존합니다. JSON에는 기준 버전과 제작 설정을 남깁니다. 웹 환경은 다운로드로 제공하며 사용자 컴퓨터에 자동 저장하지 않습니다. 출력 파일은 Git에서 제외됩니다.

## 지정 폰트

OTF/TTF 파일의 경로를 함께 지정할 수 있습니다. 정확한 폰트 적용은 빈 말풍선으로 그림을 생성한 뒤 실제 폰트 파일로 대사를 조판하는 방식입니다. 폰트 이름만 생성 프롬프트에 넣는 것으로는 서체의 정확성을 보장하지 않습니다. 사용하는 환경에 폰트를 읽고 합성할 도구가 있어야 하며, 기본 대사 폰트는 **교보 손글씨 2019 Regular**이며 `assets/fonts/KyoboHandwriting2019.otf`와 `assets/font-set.json`에 포함되어 있습니다.

## 기준 업데이트

1. 새 원본을 스킬의 `assets/` 아래 새 버전 폴더에 넣습니다.
2. `assets/reference-set.json`과 `references/character.md`를 함께 갱신합니다.
3. 플러그인 버전을 올리고 패키지를 검증·배포합니다.
4. 팀원 환경에 업데이트가 적용되었는지 확인하고 새 대화에서 시작합니다. 기존 회차는 기록한 기준 버전을 유지합니다.

내 컴퓨터의 이미지 수정만으로 다른 팀원에게 실시간 동기화되지는 않습니다. 생성 결과를 디자이너의 확정 없이 팀 기준으로 승격하지 않습니다.

## 검증

```bash
python3 -m unittest discover -s tests -v
python3 scripts/package_plugin.py
```

저장 테스트는 파일명·시간대·원본 보존·충돌 처리·컷별 저장을 확인합니다. 실제 생성 품질 검증은 새 대화에서 기준 이미지와 함께 진행해야 합니다.

공식 문서: [플러그인 패키징](https://developers.openai.com/plugins/build/plugins), [스킬과 보조 파일](https://developers.openai.com/plugins/build/skills).
